# Aturan Cline

**Baca dan ikuti sepenuhnya `AGENTS.md` di root repo.** Skills ada di `.agents/skills/` (baca `SKILL.md` yang relevan sebelum mulai).

1. **Jangan** `git commit`, `git push`, PR, atau deploy kecuali pemilik memerintahkan langsung di pesan saat itu. **Auto-approve tidak mengubah ini.**
2. Mode **Plan** untuk analisis dan perancangan; pindah ke **Act** hanya setelah rencana disetujui.
3. Jelaskan **setiap perubahan** dan **akar masalah** setiap error.
4. **Tanya dulu** sebelum menambah dependency, mengubah skema DB, atau mengubah config inti.
5. Jangan menebak. Perbaikan yang sama gagal 2× → berhenti dan minta arahan.
